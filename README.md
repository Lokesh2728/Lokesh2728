## 🧭 About Me

I'm a **Backend Developer** who enjoys turning messy requirements into clean, reliable systems. My focus is Python — mostly **Flask, FastAPI, and Django** — backed by **SQLAlchemy, MySQL, Redis**, and secure **JWT-based authentication**.

I've shipped production systems handling real-time settlement logic, audit trails, and secure APIs — the kind of backend work where correctness and reliability actually matter, not just demos. I care about clean architecture, systems that don't fall over under load, and code that the next developer can actually read.

Right now I'm going deeper into Django internals, and exploring real-time and map-based application ideas on the side.

**Talk to me about:** backend architecture · API design · Python · database performance · a good fictional novel
